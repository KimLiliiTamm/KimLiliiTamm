## Selected work

**[masculinity-debate](https://github.com/KimLiliiTamm/masculinity-debate)** · BSc thesis, University of Tartu
RAG-grounded multi-agent debate system over 3M words of transcripts from 14 speakers. Llama 3.3 70B on 2x H200 via vLLM (SLURM), ChromaDB, three-agent annotation with Krippendorff's α 0.60 to 0.64, four-criterion faithfulness filter (88.5% first-pass). Full annotation run cost about €19 instead of an estimated €500 via cloud APIs. 87 tests.
[Live viewer](https://kimliliitamm.github.io/masculinity-debate-viewer/) · [Thesis](https://thesis.cs.ut.ee/6323256b-94ce-47bb-b249-de86718304cc)
